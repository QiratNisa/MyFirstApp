# Timer App

## Description

Timer App is a simple Android application developed using Kotlin and Jetpack Compose. It provides basic timer controls including Start, Stop, and Reset. The timer state is also preserved when the device screen is rotated.

## Features

- Start the timer
- Stop the timer
- Reset the timer
- Preserves timer state during screen rotation
- Simple and user-friendly interface

## Technologies Used

- Kotlin
- Jetpack Compose
- Android Studio

## Project Structure

The main application logic is contained in MainActivity.kt. The TimerScreen composable creates the timer interface and contains the timer state and controls. Jetpack Compose is used to build the user interface, while rememberSaveable is used to preserve the timer state during screen rotation.
